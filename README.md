## GraphQL

A collection of GraphQL mini-projects exploring schemas, data types, queries, and client-server integration.

### About

This repository contains hands-on tutorials for learning GraphQL, with separate examples for a Node.js GraphQL API, a GraphQL client, and error handling.

### Topics Covered

- **GraphQL Schemas** — defining schemas and types
- **Basic Data Types** — exploring GraphQL data types
- **Queries and Operations** — writing GraphQL operations
- **Fragments** — organizing reusable query selections
- **Unions** — exploring union types in GraphQL
- **Node.js GraphQL API** — building an API using Node.js and sample data
- **GraphQL Client** — working with a client-side application
- **Error Handling** — exploring error handling in a GraphQL API


### Purpose

This repository serves as a learning reference for understanding GraphQL fundamentals and experimenting with schema definitions, operations, and API-client interaction.
